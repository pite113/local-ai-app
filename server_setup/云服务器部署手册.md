# 云服务器部署手册（Windows Server · 国内轻量）

> 给「本地 AI 工作台」开一台云服务器，用于**客户演示**或**托管版**。
> ⚠️ 业务提醒：你的主打卖点是"数据不出门、本地部署"——云服务器是演示/托管用，别取代本地部署业务。

---

## 一、购买清单

| 项目 | 建议 |
|---|---|
| 平台 | 腾讯云 或 阿里云 → 轻量应用服务器 |
| 规格 | **2核4G**（2核2G 也能跑，4G 更稳） |
| 系统 | **Windows Server 2022**（简体中文版） |
| 磁盘 | 系统盘 40GB 即可 |
| 带宽 | 3~5M 峰值（图片展示够用） |
| 区域 | 离客户近的（华南→广州，华北→北京） |
| 价格 | 约 ¥80~120/月（新用户常有优惠，别一次买多年，先月付） |

---

## 二、购买后的第一步（10 分钟）

1. **控制台**：重置/设置管理员密码（记牢）
2. **远程登录**：本机按 `Win+R` → 输入 `mstsc` → 填服务器**公网IP** → 输入账号 `Administrator` + 密码 → 登录
3. 服务器里打开浏览器，能上网即正常

---

## 三、部署（约 20 分钟）

1. **安装 Python**（服务器里）：https://www.python.org/downloads
   - ⚠️ 安装时**务必勾选 "Add Python to PATH"**
2. **解压交付包**到：`C:\local-ai-app`（⚠️ 用纯英文路径，避免中文路径问题）
   - 交付包 = 本机双击 `一键打包.bat` 生成的 zip（也可直接 git clone https://github.com/pite113/local-ai-app）
3. **双击运行**：`C:\local-ai-app\server_setup\setup_server.bat`
   - 自动完成：装依赖 → 开防火墙8000 → 初始化配置 → 注册开机自启 → **强制开启登录验证**
4. **编辑配置**：`C:\local-ai-app\.env`
   - 把 `.env.example` 的密钥填上（DeepSeek + 硅基流动，用你自己的或客户的）
5. **启动**：双击 `C:\local-ai-app\server_setup\start_server.bat`
6. **验证**：浏览器打开 `http://服务器公网IP:8000` → 应出现**登录页**（验证码发到你邮箱）

---

## 四、安全必做（重要）

- ✅ **登录验证必须开启**（setup 脚本已强制开启；`data\auth_enabled.flag` = on）
- ✅ **Windows 防火墙**只放行 8000（脚本已做）
- ✅ **云厂商控制台 → 防火墙/安全组**：也放行 **TCP 8000**（只此一个端口；以后上 HTTPS 再改 443）
- ⚠️ 云服务器是公网机器，**任何时刻都不要关闭登录验证**（否则谁都能用你的密钥烧钱）

---

## 五、开机自启说明（和本机的区别）

- 本机用"启动文件夹"（要登录才生效）
- **服务器可能长期无人登录** → 用**任务计划程序·开机触发**（setup 脚本已注册，任务名 `LocalAIWorkbench`）
- 取消自启：任务计划程序里删除 `LocalAIWorkbench` 即可

---

## 六、日常管理

| 操作 | 方法 |
|---|---|
| 启动/停止 | 双击 `start_server.bat`；或用 `停止服务.bat` |
| 打断客户体验 | 双击 `关闭访问.bat` / `开启访问.bat`（在根目录） |
| 设置体验时长 | 双击 `设置体验时长.bat` |
| 备份 | 定期把 `C:\local-ai-app\data` 整个拷走（客户数据无价） |
| 更新版本 | 重新解压覆盖（保留 `data/` 和 `.env`），或 git pull |

---

## 七、域名与备案（想用域名时再做）

- 国内服务器绑域名 → **必须 ICP 备案**（免费，1~2 周流程）
- **备案前**：直接用 `http://公网IP:8000` 访问即可（已开登录验证，安全）
- 备案通过后：买域名（约 ¥50/年）→ 解析到服务器 → 可配 HTTPS（免费证书 Let's Encrypt，找我配）

---

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 外网打不开 8000 | 检查云厂商控制台安全组是否放行 8000 |
| 打不开但本机(服务器)能开 | 同上，安全组没放行 |
| 启动报 Python 相关错误 | Python 没装或没加 PATH |
| 登录页收不到验证码 | 检查 `.env` 的 SMTP 配置；看垃圾邮件 |
| 图片生成失败 | 检查 `.env` 的硅基流动 key 和额度 |
